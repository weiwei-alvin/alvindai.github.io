Process

How a report moves through my desk

  1. Read the references first. Last year's English report, the client's style guide and any approved term list.
  2. Fix the terms before translating. A project glossary goes into Trados with the translation memory, so the same term reads the same in chapter 1 and chapter 9.
  3. Translate in the CAT tool. Segment by segment, tables included.
  4. Check numbers, units and completeness. Every figure against the source, every segment accounted for.
  5. Check the final file. Contents page, headers, page numbers and table layout in the delivered format.

Confidentiality: client files stay on my own machine and are never uploaded to public AI tools.
